# ARNOLD'S CAT — 混ぜた絵が必ず元に戻る

絵のマス目を決まった式で並べ替えて、ぐちゃぐちゃに混ぜる。何度もくり返すと、ある回数でぴったり元の絵に戻る。自分の写真でも試せる。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/arnolds-cat/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. ▶ を押すと、絵が 1 回ずつ混ざっていく。すぐに砂嵐のようになる。
2. それでも混ぜ続けると、決まった回数でぴったり元の絵に戻る。何回で戻るかは、絵の大きさ（マスの数）で大きく変わる。
3. 大きさを変えたり、自分の写真に変えたりして試す。写真はこの端末の中だけで使い、どこにも送らない。

- 「⏮ はじめ」「◀ 1 回」「▶ / ⏸」「1 回 ▶」で動かす。元に戻ったら「戻った！」が出て止まる。
- 「半分へ」: 大きさによっては、周期のちょうど半分で絵が上下左右さかさま（180° 回した形）になる。そういう大きさのときだけ押せる。
- 速さは 3 段階（1 秒に 1・5・30 回）。「ゆっくり」では、各マスが次の場所へすべっていく。
- 絵を押しているあいだは元の絵が見える。
- 大きさは 8〜256。おすすめ（76・124・144・101・100・50・250・10。50・250・10 は「半分へ」が押せる）、−＋（押しっぱなしで続けて変わる）、スライダーで選ぶ。
- PC では Space で再生・停止、← → で 1 回。
- 共有すると、今の大きさが URL（`?n=124` など）に入る。写真は共有に入らない。

もとは「アーノルドの猫写像」という数学の並べ替え（数学者アーノルドの名前がついている）。
マス (x, y) を (2x + y, x + y) mod N へ動かす。面積を変えない並べ替えなので、マスは重ならず、抜けもない。
並べ替え方は有限個しかないので、くり返すといつか必ず元に戻る。戻るまでの回数（周期）は 3N を越えない（Dyson・Falk, 1992。3N になるのは N = 2·5ⁿ のときだけ）。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

テスト（Node.js、フレームワークなし）:

```sh
node test.mjs
```

| ファイル | 中身 |
|---|---|
| `catmap.js` | 中身（1 回混ぜる・戻す、周期、k 回目の絵、半分でさかさまの判定、保存と URL の読み書き）。DOM に触らない |
| `main.js` | 画面と操作・描画・見本の絵・写真・音 |
| `test.mjs` | `catmap.js` のテスト（おすすめの大きさの周期、8〜256 の周期が 3N 以下、k 回目を直接作ったものと 1 回ずつ回したものが同じ、など） |

- 絵は 1 マス = 1 点の Canvas を CSS で拡大して描く（`image-rendering: pixelated`）。
- 周期は、行列 (2 1; 1 1) の k 乗（2 乗をくり返して計算）が mod N で単位行列になる最小の k。k 回目の絵は、元の絵に k 乗を 1 回かけて作る（「半分へ」「はじめ」）。
- 「ゆっくり」のすべる動きは、絵に重ねた Canvas（1 マス = 数点、全体で 1024 点まで）に毎フレーム描く。`prefers-reduced-motion` のときはすべらない。
- 保存は `arnolds-cat.state`（`{ v: 1, n, speed, pic, sound, seenHelp }`）。回数と写真は保存しない。
- 写真はまん中の正方形を 512 点までに縮めてメモリにだけ持つ。localStorage にも IndexedDB にも入れず、どこにも送らない。
- 見本の絵（ねこ・もじ）はコードで描いている。外の画像は使っていない。
- アプリ名は `catmap.js` の `APP_NAME`（共有の文・webapp-kit）と、`index.html`（`<head>`・見出し）、`manifest.webmanifest`、この README にある。
